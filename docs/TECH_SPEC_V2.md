### 2.2 אלגוריתם
```
s = BOXES.FIRST_S (150)
while s < finishS - BOXES.LAST_MARGIN (80):
    s += uniform(BOXES.GAP_MIN 80, BOXES.GAP_MAX 180)
    group = rng() < BOXES.PAIR_CHANCE (0.35) ? 2 : 1
    for each box in group (up to 8 attempts per box):
        bs = s + (box index) * uniform(0, 6)
        lim = halfWidth(bs) - 2.5            // canyon: about ±3.5
        bd = uniform(-lim, lim)
        reject if:
          - bs is inside a ramp zone [r.s - r.len - 25, (r.gap ? r.gap.to : r.s) + 25]
          - track.inGap(bs)
          - cliff segment and bd is more than hw - 4 toward the cliff side
          - distance in (s,d) to a fixed obstacle < BOXES.OBSTACLE_CLEAR (4)
          - second box of a pair: |bd - first.d| < 3.5
        accept -> push { id, s: bs, d: bd, t: 0 }
```
- **ציפייה:** בערך 20-32 קופסאות למרוץ.
- **דטרמיניזם:** אותו seed נותן אותה פריסה.

## 3. V2-B: התנגשויות שמזיזות

### 3.1 מצב חדש במכונית (`Car.js`)
- `vd` היא מהירות צדדית חיצונית (מ'/ש'), נוספת לתנועה מההיגוי. בכל צעד: `d += vd * dt` ו-`vd *= exp(-BUMP.LAT_DAMP * dt)` (`LAT_DAMP = 3`).
- **קיר:** אם `vd` דוחפת לתוך הקיר, אז `vd = -vd * 0.3`.
- **צוק:** הלוגיקה הקיימת (`|d| > hw` בצד `cliff`) מטפלת בנפילה, כלומר דחיפה מעל צוק מפילה.
- **פגיעה חדשה, `'shove'`:** `HIT_TIME.shove = 0.7`, `HIT_SPEED_MULT.shove = 0.85`, היגוי רועד כמו `slip` אבל באמפליטודה 0.35.

### 3.2 `collisions.js` (שכתוב)
לכל זוג מכוניות במצב `driving`:
1. **הפרדה:** כמו היום (אליפסה `A = 2.1`, `B = 1.0`).
2. **נורמל:** במרחב האמיתי, הגרדיאנט של האליפסה מנורמל: `n = normalize(Δs/A², Δd/B²)`, מכיוון a ל-b.
3. **מהירויות במרחב המסלול:** `v = (speed·cos(yaw), speed·sin(yaw) + vd)`.
4. **מהירות יחסית לאורך הנורמל:** `vrel = (vb - va)·n`. אם `vrel ≥ 0` (מתרחקים) מדלגים, או אם הזוג עדיין ב-cooldown (`BUMP.PAIR_COOLDOWN = 0.25` שניות, נשמר ב-Map לפי מזהה הזוג).
5. **מסה:** 1. בטורבו `BUMP.TURBO_MASS = 2`.
6. **מתקף:** `J = -(1 + e)·vrel / (1/ma + 1/mb)`, עם `e = BUMP.RESTITUTION = 0.3`.
7. **החלה:**
   - `a`: רכיב ה-s של `-J·n/ma` נכנס ל-`speed`, ורכיב ה-d נכנס ל-`vd`.
   - `b`: אותו דבר עם `+J·n/mb`.
   - תקרות: `|Δspeed| ≤ 6`, `|vd| ≤ BUMP.MAX_VD (9)`.
8. **סיבוב חרטום:** `yaw += clamp(Δvd * 0.03, -0.25, 0.25)` לכל אחת מהמכוניות.
9. **מכה חזקה:** אם `|vrel| > BUMP.SHOVE_REL (6)`, אז `applyHit(lighter, 'shove')`, והכבדה לא נפגעת. השיוויון נשבר לטובת זו שבטורבו.
10. **אירוע:** `world.events.push({ type: 'collide', a, b, strength: |vrel|, s, d })`.

התנגשות היא אירוע עולם, ולכן `resolveCarCollisions(cars, world)` מקבלת עכשיו את `world`.

### 3.3 בוטים אגרסיביים
- ב-`createBrain` מוסיפים `aggression ∈ [0.2, 0.7]`.
- ב-`driveBot`: אם יש מכונית צמודה מהצד (`|Δs| < 3` ו-`1.5 < |Δd| < 4.5`), אין צוק בשני הצדדים, ו-`rng() < aggression · dt · 0.8`, אז `brain.nudgeT = 0.6`. בזמן ה-nudge, ה-`target` הוא `other.d`.

### 3.4 תצוגה וסאונד (`Game.handleEvents`)
- **ניצוצות:** 8-14 חלקיקים צהובים-לבנים (מהירים, חיים 0.25 שניות) בנקודת המגע.
- **סאונד:** `Sound.clank(strength)`: רעש high-pass ב-3 קילוהרץ, 0.12 שניות, וטון של 180 הרץ.
- **אם השחקן מעורב:** `rig.shake(0.08 + strength * 0.03)` ו-`navigator.vibrate?.(25)`.

### 3.5 איזון
מריצים 30 מרוצים מדומים ובודקים שזמני הסיום עדיין 80-100 שניות, ושאין יותר מ-1 נפילה בממוצע למרוץ בגלל דחיפות (סופרים `respawns` לפני ואחרי).

### 3.6 בדיקות (`tests/unit/bump.test.js`)
- **כיוון:** מכונית שנפגעת מימין (`b.d > a.d`, b נע שמאלה לעברה) מקבלת `vd < 0`, כלומר נזרקת שמאלה. מכה משמאל זורקת ימינה.
- **ממאחור:** הקדמית מאיצה, האחורית מאטה, וסכום `speed` נשמר בטווח של ±15%.
- **מסה:** בטורבו הדוחף מאבד פחות ממי שנדחף, ומקבל `shove` רק אם הוא הקל.
- **cooldown:** אין מתקף כפול באותו זוג תוך 0.25 שניות.
- אין NaN גם בחפיפה מלאה, ו-`vd` דועכת לפחות מ-0.1 תוך 2 שניות.
- **קירות וצוק:** קיר עוצר את `vd`, ודחיפה ליד צוק בצד הצוק מפילה (`state = 'falling'`).
- מכוניות במצב `finished`, `falling`, `respawning` או `eliminated` לא משתתפות.
- **אינטגרציה:** הבדיקה `tests/unit/directions.test.js` מורחבת. מכונית ב-`vd > 0` זזה לצד ימין של המסך, דרך קוד המצלמה האמיתי.

---

**סטטוס: V2-B הושלם.** מה שונה ממה שתוכנן, לפי מדידה ב-40 מרוצים מדומים:
- **גודל מגע בין מכוניות:** `bump.CONTACT_A = 4.2`, `CONTACT_B = 1.9` (סכום חצאי הגדלים, אורך 4.3 ורוחב 1.9). הקבוע הישן `race.COLLIDE_B = 1.0` היה חצי רוחב, ולכן מכוניות "נגעו" רק בחפיפה של כמעט מטר. הוא נשאר רק לפגיעות של פריטים.
- **רף להחלקה (`shove`):** `SHOVE_REL = 9` ולא 6, ואירועי משוב (ניצוצות, צליל, רעידה) רק מעוצמה 3 (`EVENT_MIN`). ברף 6 נוצרו 17 החלקות למרוץ, וזה הרגיש כמו מכוניות מתנגחות.
- **זינוק מהיר:** המכונית מתחילה ב-45% מהמהירות ולא ב-100%, כי על הגריד המכוניות במרחק 6 מ' זו מזו והזינוק יצר התנגשויות של 30+ מ'/ש'.
- **בוטים:** כל בוט נוסע בנתיב אישי (כ-4 מ' בין נתיבים). בוט שמגיע לרכב איטי לפניו עוקף אותו (ב-90% מהמקרים), והתחככות כוונית נדירה ואינה מתרחשת ליד צוק. `driveBot` מקבל `aggression` אישי.
- **תוצאות:** כ-35 התנגשויות (עוצמה 3+) ו-9 החלקות למרוץ, נפילות 0.1 למרוץ, זמני סיום 83-85 שניות, והשחקן המדומה מנצח 40% ומסיים אחרון 12%. החזקות ביותר (25+, כ-1.2 למרוץ) הן טורבו שפוגע ברכב שנעצר אחרי מוקש.
- **חוק אחד שלמדתי:** בפנייה, "כוח הסחיפה" של הכביש מבטל חלק גדול מדחיפה צדדית (עד 6 מ'/ש'), ולכן דחיפה לכיוון צוק מפילה רק מקטע ישר או רכב שכבר קרוב לקצה.

## 4. V2-C: המכבש

### 4.1 קבצים
- **חדש:** `src/sim/roller.js` עם `createRoller()` ו-`stepRoller(world, dt)`.
- **חדש:** `src/render/RollerModel.js`.
- **שינויים:** `World.js`, `race.js`, `Car.js` (מצב `eliminated`), `BotDriver.js`, `Game.js`, `hud.js`, `Sound.js`.

### 4.2 מצב והפעלה
```js
roller = { active: false, s: 0, speed: 0, startS: 0, warned: false }
// config.roller:
START_FRACTION: 0.25, SPAWN_BEHIND: 80, SPEED_START: 0.85, SPEED_END: 0.97, ACCEL: 4,
REACH: 1.0, RESPAWN_AHEAD: 30, DANGER_DIST: 60, VIBRATE_DIST: 25, STOP_AT_FINISH: true
```
- **הפעלה:** כשה-`leaderS ≥ START_FRACTION · finishS`. אז `active = true` ו-`s = min(s של כל מכונית במצב driving/falling/respawning) - SPAWN_BEHIND`, `speed = 0.6 · CRUISE`. נשלח אירוע `roller-start`.
- **מהירות יעד:** `CRUISE · lerp(SPEED_START, SPEED_END, clamp((s - startS)/(finishS - startS)))`, והמהירות מתקרבת אליה בתאוצה `ACCEL`.
- **עצירה:** כש-`s ≥ finishS`, אז `active = false`. המכבש לא חוצה את קו הסיום.

### 4.3 דריסה
- **תנאי:** מכונית במצב `driving` עם `car.s - 2.1 ≤ roller.s + REACH` נדרסת. רוחב המכבש הוא כל הכביש, ולכן `d` לא משנה. גם מגן וחסינות לא מגינים.
- **מה קורה:** `car.state = 'eliminated'`, `car.eliminatedTime = world.time`, `car.speed = 0`, `world.eliminated.push(car)`, ונשלח אירוע `flattened`.
- **מצבי `falling` ו-`respawning`:** לא נדרסים. הם מטופלים בכלל החזרה (§4.4).
- **`Car.step`:** מכונית ב-`eliminated` לא זזה.

### 4.4 חזרה מנפילה מול המכבש
- ב-`World.step`, אחרי `stepCar`: אם מכונית עברה עכשיו מ-`respawning` ל-`driving` (`respawns` גדל), והמכבש פעיל, ו-`car.s < roller.s + RESPAWN_AHEAD`, אז `car.s = track.safeSpawnS(roller.s + RESPAWN_AHEAD)` ו-`lastCheckpointS = car.s`.
- **`track.safeSpawnS(s)` (חדש ב-TrackModel):** אם `s` בתוך ערוץ או אזור רמפה, מזיזים קדימה ל-`gap.to + 10` או `r.s + 15`.

### 4.5 סוף מרוץ ודירוג
- **סוף מרוץ:** `world.done = finishOrder.length + eliminated.length === cars.length`.
- **`computeRanks`:** קודם מי שסיים (לפי זמן), אחריו מי שעדיין במרוץ (לפי `s`), ובסוף מי שנדרס. בין הנדרסים, מי שנדרס מאוחר יותר מדורג גבוה יותר.
- **`place` לנדרסים:** נקבע בסוף המרוץ, אחרי כל מי שסיים.
- **מנגנון הבטיחות הקיים** ("60 שניות אחרי שהשחקן סיים"): חל גם אחרי שהשחקן נדרס.
- **מנגנון ההשוואה:** כשהשחקן `eliminated`, הוא כבוי (`rb = 1`), כמו כשהשחקן סיים.

### 4.6 בוטים
- ב-`driveTurbo`: אם המכבש פעיל ו-`car.s - roller.s < 70`, משתמשים בטורבו מיד.
- ב-`driveItems`: אם המכבש קרוב (פחות מ-50 מ') והבוט מחזיק מגן, הוא **לא** משתמש בו, כי המגן לא מגן מהמכבש.

### 4.7 משחק (`Game.js`)
- **השחקן נדרס:** `state` עובר ל-`spectate` עם הבאנר "נדרסת! 🫓". מכאן אותה זרימה כמו אחרי סיום.
- **`enterResults`:** הטבלה מציגה "נדרס" במקום זמן, ובכותרת: "נדרסת" או "מקום N".
- **`handleEvents`:**
  - `roller-start`: הודעה "⚠️ המכבש יצא לדרך!" (toast ל-2 שניות), צופר ורעידה קלה.
  - `flattened`: אנימציית מעיכה ו-`Sound.squash()`. אם זה השחקן, גם `vibrate([60, 40, 120])`.
- **בכל פריים:**
  - `dist = player.s - roller.s`.
  - אם `dist < DANGER_DIST`: `#danger` (מסגרת אדומה מהבהבת), ועוצמתה עולה ככל שהמרחק קטן.
  - אם `dist < VIBRATE_DIST`: `vibrate(30)`, לכל היותר פעם בשנייה.
  - רעש המנוע של המכבש: `Sound.rollerRumble(distanceGain(dist from camera target))`.

### 4.8 תצוגה
- **`RollerModel`:** ממוזג ל-4-5 רשתות:
  - תוף פלדה, `CylinderGeometry(2.6, 2.6, 1, 24)` מסובב לרוחב. `scale.y = 2·halfWidth(s) + 1`, מעודכן בכל פריים כדי להתאים לקניון.
  - מסגרת צהובה עם פסי אזהרה, תא נהג וארובה.
  - פנסים.
  - עשן: חלקיקים אפורים מהארובה, דרך `Particles`.
- **מיקום:** `track.toWorld(roller.s - 3, 0, 0)`, לפי ה-heading של המסלול. התוף מסתובב לפי `speed / 2.6`.
- **צל:** blob גדול (6×8).
- **פס ההתקדמות:** נקודה אדומה גדולה עם 🚜 ב-`roller.s / finishS`.
- **מעיכה (`v.flattenT`):**

## 5. V2-D: מראה מציאותי

### 5.1 טקסטורות CC0
- **רשת:** הסביבה מאשרת את `dl.polyhaven.org` ו-`api.polyhaven.com` (אושר על ידי המשתמש).
- **הורדה:** הפקודה עלולה לדרוש אישור הרשאה מהמשתמש בסשן. במקרה כזה צריך לבקש ממנו לאשר, ולא לעקוף.
- **סקריפט חדש, `tools/fetch-textures.mjs` (Node, מורץ ידנית ולא ב-build):**
  1. `GET https://api.polyhaven.com/assets?t=textures` → בחירת נכסים לפי תגיות וקטגוריות:
     - **road:** תגית `asphalt` (עדיף "road" או "asphalt", בלי סימוני נתיב).
     - **sand:** `sand` (עדיף חול מדברי או חוף בגוון חם).
     - **rock:** `rock`/`cliff` בגוון אדום-חום.
     - בוחרים את הנכס עם `download_count` הגבוה ביותר שמתאים.
  2. `GET https://api.polyhaven.com/files/<id>` → קבצי `Diffuse`, `nor_gl` ו-`Rough` ב-`1k` ובפורמט `jpg`.
  3. שמירה ב-`public/textures/<role>/{diff,nor,rough}.jpg` (Vite מעתיק את `public` ל-`dist`).
  4. `GET https://api.polyhaven.com/info/<id>` → כתיבת `docs/CREDITS.md`: שם, מזהה, כתובת הדף, יוצרים, רישיון CC0.
- **גודל:** סכום הקבצים ≤ 6MB. אם עולה, מקטינים ל-512 פיקסלים את ה-rough (sharp מ-npm, כ-devDependency).
- **הקבצים נכנסים ל-git.** הם קטנים, וכך הבנייה ב-CI לא תלויה ברשת.

### 5.2 טעינה וגיבוי
- **`src/render/textures.js`:** `loadTextureSet(role)` מחזיר Promise של `{ map, normalMap, roughnessMap }` או `null`.
  - `TextureLoader` עם `colorSpace = SRGB` ל-map בלבד, `wrapS/T = Repeat` ו-`anisotropy` לפי רמת האיכות.
- **טעינה לא חוסמת:** המשחק מתחיל עם החומרים הפרוצדורליים הקיימים, ומחליף ברגע שהטקסטורות נטענו.
- **אם אין קבצים** (404 או חסימה): נשארים עם הפרוצדורלי, בלי שגיאות קונסול. משתמשים ב-`console.warn` בלבד.

### 5.3 UV
- **כביש:** u לרוחב (0 עד 2, שני חזרות על רוחב הכביש), ו-`v = s/8`. מוסיפים attribute של uv לכל רצועות ה-`Strip`.
- **שוליים, שטח, רמה ותחתית צוק:** UV במרחב העולם, `(x/14, z/14)`, ונשמרים צבעי הקודקודים כגוון.
- **קירות קניון, פני צוק ורמפה:** u לאורך `s/10`, ו-v לפי הגובה `/10`.

### 5.4 חומרים לפי רמת איכות (`applyQuality` מחליף `mesh.material`)
| רמה | כביש, שטח, סלע | מכונית |
|---|---|---|
| 3 | `MeshStandardMaterial` עם map, normalMap ו-roughnessMap, anisotropy 8 | `MeshPhysicalMaterial` עם clearcoat 1, clearcoatRoughness 0.08, metalness 0.35, roughness 0.3, envMapIntensity 1 |
| 2 | Standard עם map ו-normalMap | Standard, metalness 0.25, roughness 0.35, עם env map |
| 1 | Lambert עם map | Standard בלי env map |
| 0 | החומרים הנוכחיים (פרוצדורלי, בלי טקסטורות) | כמו היום |

### 5.5 תאורה
- **שמיים:** `three/examples/jsm/objects/Sky.js` מחליף את רקע הגרדיאנט. `turbidity 6`, `rayleigh 1.6`, `mieCoefficient 0.006`, והשמש בכיוון `sunDir` הקיים.
- **השתקפויות:** `PMREMGenerator.fromScene(skyScene)` פעם אחת בטעינה, לתוך `scene.environment`. מפעילים רק ברמות 2-3.
- **ערפל:** הצבע לפי האופק של ה-Sky. כל פריים דוגמים את `sky.material` (או משתמשים בקבוע שנמדד).
- **ה-sprite של השמש:** נשאר (זוהר), אבל קטן יותר, כי ה-Sky מצייר את הדיסק.

### 5.6 צללים (רמה 3 בלבד)
- `renderer.shadowMap.enabled = true`, מסוג `PCFSoftShadowMap`.
- `sun.castShadow = true`, `mapSize 1024`, מצלמת ortho ±35 מ' שעוקבת אחרי מטרת המצלמה. `sun.target` מתעדכן בכל פריים, ו-`shadow.bias = -0.0005`.
- **הטלה וקבלה:** רשתות המכוניות והמכבש מטילים צל. הכביש, הרצועות, השטח והרמפה מקבלים צל.
- **צלליות blob:** כבויות כשהצללים האמיתיים פעילים.
- **ירידה לרמה 2:** `shadowMap.enabled = false` וגם `sun.castShadow = false`, כדי לחסוך את ה-pass.

### 5.7 מכונית מפורטת
נשאר בקוד, ממוזג לעד 10 רשתות (+גלגלים).
- **פרופיל צד:** 12-16 נקודות עם `curveSegments: 6`, דרך `Shape.quadraticCurveTo`, לקימורי חרטום וגג.
- **גוף:** קשתות גלגלים כחתכים בפרופיל (`Shape.holes` אינו מתאים: משתמשים בצורת "מגן כנף" נפרדת), ספי צד, מפזר אחורי, מראות ותא זכוכית עם מסגרת.
- **גלגלים:**
  - צמיג: `LatheGeometry` לדופן מעוגלת.
  - חישוק: 5 חישורים (`BoxGeometry` מסובבים) ממוזגים.
  - דיסק בלם אפור.
- **אורות:** עדשות פנסים קדמיים (`SphereGeometry` חצויה) ופס אחורי.

### 5.8 תנועה ריאליסטית (רינדור בלבד, ב-`Game.updateViews`)
- **מתלה:** קפיץ-בולם לכל מכונית: `y'' = -k·y - c·y' + impulses`, עם `k = 90` ו-`c = 12`.
  - נחיתה: מתקף `-vy·0.15`.
  - חבטה או התנגשות: מתקף לפי עוצמה.
  - הגובה מוחל על `body.position.y`, ומוגבל ל-±0.25.
- **נטייה בפנייה:** `body.rotation.z = clamp(-latAccel·0.012, ±0.12)`, כש-`latAccel = speed · yawRate`.
- **pitch:** בתאוצה (טורבו) האף עולה ב-0.04, ובהאטה חדה יורד.
- **גלגלים קדמיים:** `wheel.rotation.y = steer · 0.45`. אלה גלגלים 0 ו-1, והגלגל עצמו עטוף ב-Group נוסף לסיבוב ההיגוי.
- **חוזה הכיוון:** `steer > 0` מפנה את הגלגלים הקדמיים ימינה. בדיקה ב-`directions.test.js`: הקצה הקדמי של החישוק זז ל-+x בעולם כשהמכונית פונה ל-‎-z.

### 5.9 אווירה
- **אובך:** ערפל `FogExp2` עם צפיפות 0.0018 במקום `Fog` הליניארי.
- **אבק באוויר:** 40 חלקיקים קבועים סביב המצלמה, ברמה 3 בלבד.
- **Bloom:** **לא** כברירת מחדל, כי הוא יקר בטלפון. אפשר לבדוק עם `?bloom=1` דרך `EffectComposer` ו-`UnrealBloomPass` (strength 0.35, threshold 0.9), ולהפעיל לרמה 3 רק אם `smoke:perf` עומד בתקציב.

### 5.10 בדיקות

  - תקציבים לכל רמה (3: עד 130 קריאות, 0-2: עד 100).

  - החלפת חומרים: ברמה 3 החומר של הכביש הוא `MeshStandardMaterial` עם normalMap, וברמה 0 אין `map` מטקסטורה חיצונית.
